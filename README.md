> A production-ready text summarization web application powered by Hugging Face T5 models

## ✨ Features

- 🚀 **FastAPI Backend** - High-performance async API
- 🤖 **AI-Powered** - Uses Hugging Face T5 models for intelligent summarization
- 🎨 **Clean UI** - Responsive web interface with real-time updates
- 🔄 **Multiple Models** - Automatic fallback between t5-small, t5-base, and more
- 🛡️ **Robust Error Handling** - Comprehensive error management and retry logic
- 📊 **Health Checks** - Built-in monitoring endpoint
- 🔐 **Secure** - Token-based authentication for API access
- 📦 **Easy Deployment** - Ready for Hugging Face Spaces, Render, or any cloud platform
